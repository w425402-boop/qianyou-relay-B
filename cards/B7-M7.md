## 1. 你这一棒交付什么

**为什么拆给你**：集中考察复杂个人资料面板的页内编辑态切换、枚举下拉/多选交互，以及跨模块聚合查询（发起/参与/收藏/动态）。

逐条交付，不许减项：

1. **资料页显示 10 项**：头像、昵称、性别、年龄、城市、MBTI、职业、兴趣、标签、简介。
2. **编辑资料**：点"编辑"进编辑态，"保存"生效、"取消"不存；校验昵称非空 2–12 字、年龄 18–80 数字，不过标红提示；支持 3 个预置头像点按切换、6 城下拉、16 型 MBTI 下拉、兴趣/标签多选（兴趣至少 1 个）。

4. **收藏与关注**：★（收藏）与"＋关注"可切换，存 `store.favorites` 与 `store.follows`，刷新不丢。
5. **动态**：显示由报名/发布自动生成的记录（如"我报名了{活动标题}"），无记录显示"暂无动态"。

## 2. 契约前置（先看契约再写代码，10 分钟）

## 3. 定桩说明（本棒要摘掉的桩）

开局五个函数是 `QY.seam.stub('M7 QY.toggleFavorite')` 形态，一调用即抛 `[SEAM 未实现]`。

**交付标准**：M7 的 5 个契约函数全部不再是桩，`node tests/contract.js` 的「本棒模块仍是桩」检查转绿。

```js
// js/modules/mine.js —— 从桩到真实现（编辑态 + 两个 toggle 是重点）
(function (root) {
  var QY = (root.QY = root.QY || {});
  var ME = 'u01';
  var editing = false;                                  // 编辑态是本模块的私有状态，不进 store

  // 契约函数：只校验，不写库。check.js 直接断言布尔
  QY.validateProfile = function (patch) {
    var p = patch || {};
    var nick = String(p.nickname == null ? '' : p.nickname).trim();
    if (nick.length < 2 || nick.length > 12) return false;             // 昵称 2–12 字
    var age = Number(p.age);
    if (!(Math.floor(age) === age && age >= 18 && age <= 80)) return false;
    if (p.interests !== undefined && (!Array.isArray(p.interests) || p.interests.length < 1)) return false;
    return true;
  };

  // 契约函数：部分更新，只动 u01，未传字段保留原值
  QY.updateProfile = function (patch) {
    if (!QY.validateProfile(patch)) return { ok: false, errors: { reason: '校验未通过' } };
    var state = QY.store.load();
    for (var i = 0; i < state.users.length; i++) {
      if (state.users[i].id !== ME) continue;                          // 别人的用户数据一律不碰
      for (var k in patch) if (Object.prototype.hasOwnProperty.call(patch, k)) state.users[i][k] = patch[k];
      QY.store.save(state);
      return { ok: true, user: state.users[i] };
    }
    return { ok: false, errors: { reason: '当前用户不存在' } };
  };

  // 契约函数：收藏切换。数组里有就删、没有就加，返回切换后状态
  function toggleInArray(arrKey, id) {
    var state = QY.store.load();
    if (!Array.isArray(state[arrKey])) state[arrKey] = [];
    var i = state[arrKey].indexOf(id);
    if (i > -1) state[arrKey].splice(i, 1); else state[arrKey].push(id);
    QY.store.save(state);
    return i === -1;                                                   // true = 现在是已收藏/已关注
  }
  QY.toggleFavorite = function (id) { return id ? toggleInArray('favorites', id) : false; };
  QY.toggleFollow = function (uid) { return (!uid || uid === ME) ? false : toggleInArray('follows', uid); };

  // 渲染：10 项 + 编辑态切换（当前页完成，不跳页）+ 发起/参与/收藏/动态四区
  QY.renderMine = function () { /* 「暂无活动」「暂无动态」空态逐字照写 */ };
})(typeof window !== 'undefined' ? window : globalThis);
```

三个坑：①编辑态必须在**当前页**切换，做成整页跳转直接违反禁令；②`store.users` 里 u01 初始昵称是"我"，1 个字——按"2–12 字"校验，初始值本身就通不过，交接单要写明"仅校验用户新输入，不校验展示态"；③多选兴趣至少 1 个，全删光时保存要标红而不是静默存空数组。
