## 1. 你这一棒交付什么

**为什么拆给你**：发现页是用户打开 App 第一眼看到的页，只依赖 M1 的数据；列表＋分类＋筛选＋搜索＋排序边界清晰，适合第二棒独立做。

逐条交付，不许减项：

1. 实现 `QY.renderDiscover()`：每条卡片显示 **6 项**——标题、时间（"11月29日 19:00"格式）、地点、费用（"人均 ¥25"，0 费用显示"免费"）、已报人数/上限（"3/8人"）、分类标签；默认按 `time` 升序。
2. 分类栏：**全部＋6 个分类**（美食、咖啡、桌游、运动、文娱、户外），点击切换只显示该分类活动。
3. 筛选（**两个条件可叠加**）：费用区间（全部 / 免费 / ¥50以下 / ¥50以上）、人数状态（全部 / 有名额 / 已满员）。
4. 搜索框：按**标题或地点**包含匹配，不区分大小写；搜不到显示"没有找到相关活动"。
5. 排序切换：**时间最近**（time 升序）/ **人气最高**（joined 倒序），默认时间最近。
6. 点卡片跳 `#/detail/:id`；实现 `QY.filterActivities(list, { category, cost, availability })` 与 `QY.searchActivities(list, keyword)` 两个**纯函数**供 check.js 调用。

**交付物**：`js/modules/discover.js`；`tests/check.js` 里追加 3 条断言（分类筛选计数、费用筛选计数、搜索结果）；《交接单》。

## 2. 契约前置（先看契约再写代码，10 分钟）

对照 CONTRACT.md 第 4 节，本棒 3 个对外函数：

| 函数 | 入参 | 返回值 | 出错行为 |
| :--- | :--- | :--- | :--- |
| `QY.renderDiscover()` | 无 | 渲染 `#activity-list`，返回 `undefined` | 容器不存在 → 静默返回，不抛 |
| `QY.filterActivities(list, cond)` | `list: Activity[]`、`cond: { category, cost, availability }` | 过滤后的新数组，**不修改入参** | `cond` 缺省/空对象 → 返回全部；值为"全部" → 该条件不生效 |
| `QY.searchActivities(list, kw)` | `list: Activity[]`、`kw: string` | 匹配后的新数组 | `kw` 空串/`null` → 返回原列表副本 |

`cost` 取值：`'all'` / `'free'` / `'lt50'` / `'gte50'`；`availability`：`'all'` / `'open'` / `'full'`。**边界自己定并写进交接单**（建议 ¥50 归"¥50以上"），check.js 按你的交接单口径核对。

**只许改（owns）**：`js/modules/discover.js`
**只许追加（appendOnly）**：`css/style.css`（只追加 M2 区块）、`tests/check.js`（只追加 M2 断言）

## 3. 定桩说明（本棒要摘掉的桩）

开局你的三个函数是 `QY.renderDiscover = QY.seam.stub('M2 QY.renderDiscover')` 形态，被调用即抛 `[SEAM 未实现]`。

**交付标准**：M2 的 3 个契约函数全部不再是桩，`node tests/contract.js` 的「本棒模块仍是桩」检查转绿。

```js
// js/modules/discover.js —— 从桩到真实现
(function (root) {
  var QY = (root.QY = root.QY || {});
  var state = { category: 'all', cost: 'all', availability: 'all', keyword: '', sort: 'time' };

  // 格式化手写：不用 toLocaleString，不同 Chrome 输出不一致
  function fmtTime(iso) {
    var d = new Date(iso);
    return (d.getMonth() + 1) + '月' + d.getDate() + '日 ' +
           ('0' + d.getHours()).slice(-2) + ':' + ('0' + d.getMinutes()).slice(-2);
  }
  function fmtCost(c) { return c === 0 ? '免费' : '人均 ¥' + c; }
  function fmtJoined(a) { return a.joined + '/' + a.capacity + '人'; }

  // 纯函数：条件叠加，全部白名单判断，绝不改入参
  QY.filterActivities = function (list, cond) {
    var c = cond || {};
    return (list || []).filter(function (a) {
      if (c.category && c.category !== 'all' && a.category !== c.category) return false;
      if (c.cost === 'free'  && a.cost !== 0) return false;
      if (c.cost === 'lt50'  && !(a.cost > 0 && a.cost < 50)) return false;
      if (c.cost === 'gte50' && !(a.cost >= 50)) return false;          // ¥50 归此档
      if (c.availability === 'open' && !(a.joined < a.capacity)) return false;
      if (c.availability === 'full' && !(a.joined >= a.capacity)) return false;
      return true;
    });
  };

  // 纯函数：标题或地点包含匹配
  QY.searchActivities = function (list, kw) {
    var k = String(kw == null ? '' : kw).trim().toLowerCase();
    if (!k) return (list || []).slice();
    return (list || []).filter(function (a) {
      return String(a.title).toLowerCase().indexOf(k) > -1
          || String(a.place).toLowerCase().indexOf(k) > -1;
    });
  };

  // 渲染：读 store → 分类 → 筛选 → 搜索 → 排序 → 写 #activity-list
  QY.renderDiscover = function () { /* 每卡片 6 项；满员打「已满员」标签；点卡片 location.hash = '#/detail/' + a.id */ };
})(typeof window !== 'undefined' ? window : globalThis);
```

两个坑：①空态文案必须逐字是"没有找到相关活动"（验收清单按字核）；②排序的比较器要防脏数据——`new Date(x.time) - new Date(y.time)` 遇到非法时间会得到 `NaN`，先洗一遍数据再排。
